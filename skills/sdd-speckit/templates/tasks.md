- **입력**: `specs/NNN-<이름>/` (plan.md, spec.md 필수 / data-model.md, contracts/, research.md, quickstart.md 있으면)
- **테스트**: 필수 (constitution III. 비즈니스 규칙마다 테스트)

## 형식: `- [ ] T001 [P] [US1] 설명 — 파일 경로 — 선행: T000`
- **[P]**: 병렬 가능(다른 파일, 미완료 작업에 의존 없음)
- **[US1]**: 유저 스토리 phase의 작업에만 붙인다(준비·기반·마무리 phase는 없음)
- 작업 하나 = 커밋 하나 크기(반나절~1일). 파일은 여러 개 적어도 된다. data-model의 제약(길이, 필수, enum 값)은 설명에 그대로 옮긴다.
- 이슈 트래커 연동 시 끝에 ` — #<이슈 번호>`
