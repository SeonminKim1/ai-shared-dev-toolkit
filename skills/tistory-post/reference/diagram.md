# 흐름도·구조도 이미지

글에 흐름(단계, 요청 흐름, 레이어)이 있으면 `[이미지:]` 자리만 두지 말고 PNG를 만들어 올릴 수 있게 한다. 텍스트 코드블록 흐름도는 쓰지 않는다 (사용자가 이미지를 원함).

## 만드는 법
1. `posts/<slug>/<이름>.svg`를 직접 쓴다 (손으로 쓴 SVG 또는 짧은 생성 스크립트 `posts/<slug>/<이름>.py`). 원본을 남겨 두어 문구 수정 시 다시 그린다.
2. `<스킬 디렉터리>/scripts/render-image.sh posts/<slug>/<이름>.svg` → 같은 폴더에 `<이름>.png` (2배 해상도).
3. PNG를 Read로 열어 잘림·겹침을 확인하고, `open`으로 사용자에게 보여준다.
4. post.html에는 `<p data-ke-size="size16">[이미지: <이름>.png / 캡션]</p>`, meta.md 이미지 체크리스트에 업로드 항목을 남긴다.

## 스타일 (블로그 h2와 같은 톤)
- 캔버스: 너비 980px, 흰 배경. 루트 `<svg>`에 `width`/`height` 필수. 글꼴 `Apple SD Gothic Neo, sans-serif`.
- 색: 메인 `#43587F` (테두리·화살표·제목), 보조 `#7A869A` (메모·점선·배지), 레인 배경 `#F3F5F9`, 본문 글자 `#1F2937`. 이 외 색은 쓰지 않는다.
- 구성: 묶음(예: 요구사항 / 설계 / 구현)마다 가로 레인, 왼쪽에 레인 이름. 박스는 210×90, 3줄(굵은 이름 / 산출물 / 회색 메모).
- 선: 기본 흐름은 실선 화살표, 되돌아가기·생략 가능 경로는 회색 점선. 보조(생략 가능) 단계는 점선 박스 + '보조' 태그.
- 분기·되돌아가기가 여러 개면 출발점에 번호 배지(①②③)를 달고, 맨 아래에 번호별 설명 한 줄.
- 박스 안 글자는 본문 용어와 똑같이 맞춘다 (본문을 고치면 이미지 라벨도 같이 고친다). 이모지 X.
