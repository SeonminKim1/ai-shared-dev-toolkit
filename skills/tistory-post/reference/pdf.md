# PDF 소재 처리

- **Read 도구로 직접 읽는다** (변환 도구 없음). 10페이지가 넘으면 `pages`를 `1-20`, `21-40`처럼 20페이지씩 끝까지 읽는다.
- 표·도식은 내용으로 옮기고, 넣을 만한 그림은 `[이미지: PDF명 p.N 도식]` 자리로 표시한다.
- 읽은 뒤 `topics/<slug>/_digest.md`에 파일별 핵심 요약(파일명, 페이지 범위, 핵심 bullet, 쓸 만한 수치·용어·그림 위치)을 남긴다. 소재 추가·재작성 때는 digest를 먼저 보고 새 PDF만 읽어 덧붙인다 (읽은 PDF는 다시 읽지 않는다).
- PDF가 여러 개면 **글 1개로 합칠지, 연재 (1), (2)…로 나눌지**도 유형 질문에 함께 묻는다.
- 발표 슬라이드는 슬라이드 제목을 섹션 후보로 삼는다. 강의·문서는 요약 원칙에 맞게 압축하고 원문 문장을 길게 옮기지 않는다.
- 출처(강의, 책, 발표 자료)가 드러나면 meta.md에 적고, 본문 끝 `참고 문서`에 한 줄 남길지 사용자에게 확인한다.
