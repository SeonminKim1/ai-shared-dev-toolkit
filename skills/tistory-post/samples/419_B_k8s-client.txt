<h2>설명
<p>k8s(Kubernetes)자원을 생성하거나 관리할 때. 다음 선언형, 명령형 방법 외에도 API Client를 이용해 어플리케이션 레벨에서 제어하는 방법이 있다.

  - **선언형 방식 (Declarative):** YAML/JSON 파일에 원하는 리소스의 상태를 정의하여 적용하는 방식<br>- 예: kubectl apply -f <파일명.yaml>
  - **명령형 방식 (Imperative):** 터미널에서 직접 명령어를 입력하여 즉시 리소스를 생성 및 조작하는 방식<br>- 예: kubectl create pod
  - **API Client 방식 (Application-level):** Python, Java 등의 고수준 API를 통해 코드 레벨에서 제어하는 방식<br>- import kubernetes; client.get_namespaced_pod_list()
<p>**API Client 방식 장점** : 친화적인 언어로 스크립트나 애플리케이션 내에 내장하여 쿠버네티스 리소스를 관리 할 수 있음
