# I. 자료 공유·링크 모음

- **발표 자료 공유** (`[세미나 자료 공유] 주제 묶음`, 회고 & 기록 / 기타 경험 & 트러블슈팅): 발표마다 h2 `N. 발표 제목`, 아래 `<p>` 네 줄 `일시 : YY.MM.DD (요일)` / `대상 : 회사 팀` / `개요 : 한 줄` / `구글 슬라이드 자료`(링크·첨부는 자리 표시). 설명은 더 붙이지 않는다.
- **좋은 글 모음** (`[공유] 좋은 개발 글 모음`, 개념 정리 / 개발 인사이트): 큰 분류 h2 (`Non-Tech 관련`, `Tech 관련`) → `<b>소분류</b>` → ul `<a>글 제목</a> : 한 줄 평 ((추천) 가능)`. 링크 여러 개는 `, <a>링크2</a>`.
- 계속 추가하는 글이라, 소재 추가 시 해당 분류에 항목만 덧붙인다.
