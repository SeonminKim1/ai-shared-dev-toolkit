# B. 실습 기록
카테고리: 클라우드 & 데브옵스 / * (인프라), 실습 기록 / * (프레임워크)

## 기본형
- `설명` → `목차` → `예제 1) ~` … → (선택) `참고 문서`
- `설명`: 무엇을, 왜. 다른 방식 비교 ul (`<b>X 방식 (영문):</b> 설명 (예: 명령어)`) → `<b>장점</b> : …`
- `목차`: `<p>예제 1) …</p>`를 줄마다 나열.
- 예제 h2 = `예제 N) 제목`. 본문은 거의 코드블록이고 **설명은 코드 주석**으로: 상단 `"""exN: 설명"""`, 단계별 `# 1. 대응 CLI 명령어`, 끝에 `# 확인:` + 검증 명령어. 공통 코드는 `# ===== config.py =====` 구분선으로 한 블록에.
- 블록 사이 `<p>` 설명은 1~2줄만.

## 변형
- **구현 순서** ([AWS Lambda] Chalice 이미지 리사이징): `서비스 설명`(관련 글 링크) → `구현 순서 (1~2)`, `구현 순서 (3) …` → `최종 기능 및 응답/에러 정리` → `기타 참고`. 단계는 `<b>N. 할 일</b>` + ul + 코드.
- **카탈로그** (DB driver 종류, Timeout 에러 분류): `개요`(또는 `요약` 표) → 항목마다 h2 → 설명 ul + 예시 코드.
- **API 레퍼런스** ([Django Ninja] CRUD 예제): 기능마다 h2 (`CRUD - Create`, `1. 타입 검증`) → ul (`api : POST /…`, `body : Schema`, 한 줄 설명) → 코드. 도입 0~2줄.
- **설치·설정 단계** (Jenkins 설치, EC2 경보 설정): `개요`(목적, 이전 글 링크) → `X 란` → `구현 방법` h2에 `<b>N. 단계</b>` + ul 1~2줄 + 코드/콘솔 캡처 이미지 자리 → (`추가`) → `참고 문헌`.
- **단일 코드 메모** (`[Utils] …`): h2 1~2개, 조건·특징 ul 3~5줄 + 코드블록 하나.
