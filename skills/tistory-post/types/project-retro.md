# C. 프로젝트 회고
카테고리: 회고 & 기록 / 프로젝트 경험기

## 기본형
- `개요` → `<서비스명> 서비스 개요` → (선택) `프로젝트 배경` → `프로젝트 진행` → `마치며`
- `개요`는 **존댓말**. 회사/프로젝트, 기간 `약 N년 N개월(YY년 M월 ~ YY년 M월)`, 한 일, 소회 1~2문장. 괄호 농담 가능 ("(물론 이것도 저만의 '기억 왜곡에 의한 미화' 일 수도 있음)").
- 서비스 개요: `<b>한줄소개</b> : …`, `<b>주요 대상 사용자</b> : …`, `<b>주요 기능</b>` + ol (`<b>기능명</b>: 설명`)
- 프로젝트 진행: 단계마다 h4 `N. 단계명`, 단계 사이 `<hr style2>`. 각 단계:
  - `<b>기간</b> : YY년 M월 ~ M월 (N개월)`, (있으면) `<b>사용 기술</b> : …`
  - `<b>핵심 내용</b>` + ul (`<b>작업명</b>: ~함/~구현함`, 문제→해결→결과)
  - `<b>회고</b>` + ul: **반말 평서체(~했다, ~것 같다)**, 배운 점·아쉬운 점, 괄호 속 TMI, `=>` 깨달음 흐름.
- `마치며`: 반말 소회 1~2문단 + 팀원 감사 한 줄 ("…팀원들에게 큰 respect를!").

## 변형
- **프로젝트 연재** ([MSA 경험기] 모아 구독 (1)~(7)): (1)편은 `시작 계기` → `프로젝트 구조 및 설계`(`<b>주제</b>`, `<b>목표</b>` ul, 구조 이미지, `<b>서비스 목록</b>` ul `서비스명 (기술) : 역할`, 본인 담당 `<b>`) → `주요 고민 사항` + 연재 목록 ul. (2)편부터 `지난 글`(이전 글 링크 + 이번 주제 1줄 + 문제 ul) → 이슈 h2 (`동시 접근 이슈 - 원인`, `- 해결 방법`), 핵심 질문은 인용구.
- **KPT 회고** (짧은 팀 프로젝트): `프로젝트 기간, 팀 구조`(주제/기간/팀/시연 링크) → `Keep` → `Problem`(`문제 => 대응`) → `Try` 각 ul → (`느낀점`). 팀원 이름·소감은 소재에 있을 때만.
