# F. 자격증·시험 후기
카테고리: 회고 & 기록 / 기타 경험 & 트러블슈팅. 제목: `[자격증] CKA 취득 후기 (26년 9월)`

- `응시 배경` → `X 시험이란` → `X 시험 특징` → `시험 준비 (강의, 자료)` → `준비 기간 및 방법 (+추천)` → `시험 결과`. 번호형(`1. AWS 자격증 구성` → … → `5. 최종 진행`)도 쓴다.
- `배경`은 반말 구어체: 말줄임표 `..`, 머뭇거림("해보고 싶었지만? 기회가 없었다"), 괄호 속 비유.
- 본문은 `<b>소제목</b>` + ul 블록 반복. 중요한 항목은 블록당 1~2개 `<b>`.
- 말버릇: `x100`(강조), `TMI)`, `개인 생각)`, `// 링크 설명`
- 자료/강의 소제목: `<b>(필수, 추천, 유료 강의) <a>(플랫폼) 강사 - 강의명</a></b>`
- 준비 기간: ol `<b>(단계, N주) : </b>설명`
