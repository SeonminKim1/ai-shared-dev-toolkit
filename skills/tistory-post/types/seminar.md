# G. 세미나·컨퍼런스 후기
카테고리: 회고 & 기록 / 기타 경험 & 트러블슈팅. 제목: `[전시회,세미나] 행사명 연도`

- 도입부 없이 바로 세션. 구분은 둘 중 하나:
  - 세션마다 h2 `(분야) 회사 - 발표 제목` (예: `(UX) 토스뱅크 - 또 혁신하기`)
  - 트랙별 h2 (`Tech 세미나`) 아래 세션 블록, 블록 사이 `<hr style2>`
- 세션 헤더: `<b>주제 : 발표 제목</b>`, `<b>발표자 : 이름 / 회사</b>`, (있으면) `<b>자료 : <a>링크</a></b>`
- 본문은 핵심 메시지를 **한 줄씩 ol** (평서문, ~다/~함 혼용). 세부는 같은 줄에 `(…)`.
- 주제가 여러 개면 `<b>1. 소주제</b>` + ul (`UX 설득`, `좋은 회의 방법`, `명언`).
- 개인 의견은 괄호로 짧게. 소재에 없는 발표 내용은 만들지 않는다.
- **전시회 변형** ([전시회, 세미나] AW 2026): `용어 정리`(분야별 `<b>분야</b>` + `약어 : Full Name : 설명` ul) → `기업 특징`(`<b>기업명</b>` + ul 또는 `<b>기업명</b> : 한 줄`) → `참고`(공식 사이트)
