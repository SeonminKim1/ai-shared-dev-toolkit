# H. 요약 / 시사·경제
카테고리: 기타 / 시사, 경제. 제목: `[경제] 월가아재 - … 요약` (`출처 - 내용 요약`)

- h2 `1. 핵심 주장 문장형 제목`을 번호로 나열. h2 아래 리드 1~2줄, 핵심은 `<b>`.
- 하위 소제목 `<b>1.1. 소제목</b>` + ol. 항목은 `<b>키워드</b>: 설명` 한 줄. 세부가 많으면 `<b>1.2. 키워드</b>`를 새로 만든다.
- 숫자 예시로 메커니즘을 푼다 (자기자본 100억 → 110억 …). `<b>핵심</b>:`, `<b>결론</b>:` 항목으로 마무리.
- 도식·영상 캡처 이미지 자리를 적당히 넣는다.
