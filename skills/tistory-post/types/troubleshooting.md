# E. 트러블슈팅 / 실무 팁
카테고리: 회고 & 기록 / 기타 경험 & 트러블슈팅 (실무 팁이면 개념 정리 / 개발 인사이트)

## h2 흐름
- 단일 원인: `문제 상황` → `원인 분석`(또는 `확인하면서 알게 된 것들`) → `해결` → (선택) `X vs Y 차이` → `한 줄 요약`
- 꼬리를 무는 해결: `요구사항 및 접근` → `문제 발생 1` → `문제 해결 1` → `문제 발생 2` → … → `최종 결론`
- 장애 대응 ([시스템 장애] Cron 과부하): `상황` → `문제 파악` → `해결`
- 실무 팁: `개요` → `1. 팁` → `2. 팁` … → `결론`
- 짧은 메모: `배경` → `(내용 주제)` → `결론 - 메모` (표 하나 + ul 3줄)
- 사례 모음: `주로 파악해야 될 부분` ul → `사례 N - 상황 한 줄` h2 반복 (`<b>오류 메시지</b>` 코드블록 / `<b>원인 / 해결</b>` ul / `<b>유의사항</b>`, `<b>결론</b>`) → `참고 문헌`. 소재 추가 시 `사례 N+1`로 붙인다.

## 서식
- 문제/해결 h2 첫 줄: `<b>문제점 : 페이지 간 데이터 중복발생</b>` / `<b>해결 방법 : 랜덤 시드 고정</b>`
- 처음 단순하게 생각한 것이나 핵심 원인 한 문장은 **인용구**: `“페이지네이션 + rand() 쓰면 되겠지?”`
- `최종 결론`: 문제점 | 원인 | 해결 표 + `<b>최종 결론</b>` ul 2~4줄. 또는 `<b>문제 결론</b>` / `<b>해결</b>` / `<b>기타 알게 된 것</b>` 라벨별 ul. `한 줄 요약`은 한 문장.
- 문체는 **반말 서술체 + 짧은 줄**: 한 문장을 `<p>` 한두 줄로 끊고 코드블록을 문장 중간에 끼운다 ("처럼 필드명을 변경한 뒤:" → [코드] → "를 수행했는데,").
- 개요는 "개선하며 알게 된 몇 가지 점을 정리해보았다." 같은 굵은 한 줄로 본론에 들어간다.
- 선택지는 `Y → 결과` / `N → 결과` ul. 비교 섹션은 h3 + ul. 해결 뒤 부가 섹션 앞에 `<hr style1>` 가능.
